# Codecademy E-commerce REST API

This project is an e-commerce application REST API built with server-side web development technologies.

## Project Objectives

- Build a functioning e-commerce REST API using Express, Node.js, and PostgreSQL.
- Allow users to register and log in through the API.
- Support CRUD operations for products.
- Support CRUD operations for user accounts.
- Support CRUD operations for user carts.
- Allow users to place orders.
- Support CRUD operations for orders.
- Develop the application locally.
- Document the API using Swagger.

## Technology Stack

- JavaScript
- Node.js
- Express
- PostgreSQL
- Swagger
